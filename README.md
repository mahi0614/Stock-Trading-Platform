# 📈 Stock Trading Platform

A full-stack stock trading platform that allows users to explore stocks, manage portfolios, and simulate buying/selling of stocks through an interactive dashboard.


## 🚀 Features

- 🔍 View and explore stock data  
- 💰 Buy and sell stocks  
- 📊 Portfolio management and tracking  
- 📈 Interactive dashboard  
- 🔐 User authentication (if implemented)  
- ⚡ Real-time UI updates  


## 🛠️ Tech Stack

Frontend:
- React.js  
- CSS / Tailwind (if used)

Backend:
- Node.js  
- Express.js  

Database:
- MongoDB  

Other Tools:
- Git & GitHub  
- REST APIs  


## 📁 Project Structure

Stock-Trading-Platform/
│── backend/
│── frontend/
│── dashboard/
│── README.md


## ⚙️ Installation & Setup

1. Clone the repository
git clone https://github.com/mahi0614/Stock-Trading-Platform.git
cd Stock-Trading-Platform

2. Setup Backend
cd backend
npm install
npm start

4. Setup Frontend
cd frontend
npm install
npm start
🔐 Environment Variables

Create a .env file in the backend folder:

PORT=5000
MONGO_URI=your_mongodb_connection_string
